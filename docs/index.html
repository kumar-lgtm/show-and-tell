Retire the red arrow.

Show and tell is a review toolbar for your local dev server. Point at the page, say or edit what should change, and your coding agent gets the note with its target.

98 seconds, with sound and captions. Landscape cut (16:9) Vertical cut (9:16) Transcript

The routine it replaces

  1. Screenshot the page.
  2. Draw an arrow on it.
  3. Paste it into the agent chat.
  4. Explain the arrow in words anyway.

A picture and a paragraph do not tell the agent which element you meant or where it lives in the source. A note left on the page does: it carries the element, the viewport, and a pointer to the file and line.

You send the notes as one round, each anchored to its element and its line in the source, so the agent does not spend a turn working out what you meant. That means fewer rounds, less usage spent re-explaining, and the decisions stay with you. It works on anything built in code that runs on a local dev server: websites, designs, videos and tools.

Four ways to say it

  • NCommentClick anything on the page and type what should change.
  • VTalkTalk while you click and box things on the page. Transcription runs free on your own machine, and each sentence comes back attached to what you were pointing at. You check the transcript before it is sent.
  • TEdit textRewrite the words in place. The agent receives the change as a from and a to.
  • Shift TAll textEvery string on the page in one view, with its role and its file and line. Made for writers and editors.

Open the bar first: click the round button in the corner, or press ⌘⇧F (Ctrl⇧F on Windows and Linux). Then press Send when you are done. The agent fixes the source, closes each note, and you check every fix and reopen what is not right.

Try it in a minute

You need Node 22.5 or newer. Nothing to install: the toolbar ships prebuilt. This starts a demo pricing page with the toolbar on it, and your notes stay on your machine.

# clone, then start the demo page
git clone https://github.com/kumar-lgtm/show-and-tell.git
cd show-and-tell
node scripts/prototype.mjs
# open http://127.0.0.1:8877, click the round button
# in the corner, then press N, V or T

Hand it to your agent

Works with Claude Code, Codex, Cursor and anything else that has a shell. Paste this into your agent from inside your project. The setup guide tells it what to do, including how to take everything out again.

It leaves nothing behind

The toolbar only loads on localhost. The one line that loads it is kept out of every commit by a local git filter, and one command restores the file byte for byte. With a framework plugin, no loader line is written to your files at all.

Show and tell is built on Agentation by Benji Taylor. Licence and third-party notices are in the repo's README and NOTICE.

The demo page in the video, Fieldnote, is fictional. The All text scene is a capture of the real view; the other toolbar scenes are drawn from the design.
